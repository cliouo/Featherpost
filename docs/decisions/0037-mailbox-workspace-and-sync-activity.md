# ADR-0037：08-B 统一邮箱工作区、批量写回与同步活动

- 状态：已接受，仓库实现完成
- 日期：2026-09-23
- 前置：[UI 规格](../design/tauri/UX-SPEC.md)、[写回队列](0027-mailbox-write-path-and-offline-queue.md)、[搜索与线程](0029-local-search-index-and-threading.md)

沿用已确认的三栏、灰白/深色外壳、墨绿强调和现有 CSS token。邮箱模块继续通过贡献注册底座
提供导航、动作、工作页与设置；本片不切换默认安装，不删除 egui，也不新增外部扩展权限。

## 查询由 daemon 分页

统一收件箱只聚合 role=inbox；全部邮件、星标、未读与具体文件夹均在 SQL 过滤后分页、计数。
`listMessageSummaries` 增加可选 `role`、`seen`、`flagged`，旧调用保持原行为。禁止先拉每个
账户的一页再在 JS 合并冒充完整统一列表。摘要身份始终是 account/folder/uid，排序由内核决定。

本地搜索用现有结构化查询，Enter 提交，支持账户/文件夹/发件人/日期/附件过滤，保留查询条件。
索引未完成明确显示覆盖提示。服务器搜索只返回未落库摘要，本片不提供可打开正文的假入口。
会话摘要按时间正序分页，跨文件夹阅读复用现有隔离正文；thread_id=0 不冒充完整会话。
`getThread` 增加可选 limit/offset 与 total，旧调用仍返回原有全部摘要。

## 批量操作与失败恢复

只选当前已加载邮件，支持复选框、Shift 范围与 Cmd/Ctrl 追加。按账户/文件夹分组，每组至多
500 UID；标记、归档、移动、删除直接调用现有 mailbox_write API。归档使用实际 role 映射，
无映射必须选目标；跨账户不提供移动。删除前列出实际策略，无 Trash 时明确是标记删除。
不提供无法保证的撤销。默认保留手动已读操作；800ms 自动已读是未冻结的独立产品选择。

本地入队回执不等于服务器完成；事务回执新增 queued_uids/unchanged_uids/missing_uids，queued 仍是新入队数；已满足目标单独计数。部分失败保留未确认项，不能把整批
当成功。换视图/账户或断连使旧读回执无效；写入快照绑定点击时的身份，不能作用于后续选择。
断连后不自动重放写调用，提示先刷新/查看活动。邮箱服务器离线但 daemon 在线时仍可本地排队。

## 活动投影与资源边界

活动页读取 settled 项，failed 不因默认过滤而消失。`listPendingOps` 增加 limit/before_id
分页及 summary_only 投影；摘要查询在 SQL 就跳过 APPEND 原文，JSON-RPC 与 JS 都不接收
邮件 payload。保留目标文件夹、标记动作、状态与尝试次数；错误说明只用受控文案，不能透传服务器回显。
源邮件主题单独有界读取（最多 512 字符，不查正文，源消息消失则缺省），摘要分支额外要求
messages_read，因此摘要查询与摘要裁决均是 mailbox_write + messages_read；原非摘要调用保持兼容。
`resolvePendingOp` 也可请求摘要回执。unknown 的重试必须明确确认可能重复副本；discard 只叫
“不再重试”，不能声称撤销。未知 kind/state 保留可见，但禁用本版本无法解释的恢复动作。

界面数据只存会话内存，浏览器存储继续只放非敏感 UI 偏好；不持久记录邮箱名称/查询/邮件内容。
列表最多保留 1000 条摘要，线程每页 30 条且最多保留 1000 条；续页总数变化时拒绝拼接并要求重开。
活动页仅在可见时每 5 秒轮询，加载超过首批 40 条历史后暂停轮询，关闭视图停止计时。schema 保持 v10。

OpenIntent.Message 增加可选 folder，新 OTP 通知从来源邮件传递；旧字段仍可解码。Tauri 遇到
缺失 folder 的旧意图只回到账户列表，不猜 UID。保存等待与后续定位共享导航代次，后续手动
操作胜出。普通到信只刷新列表，重连及显式刷新才重载当前正文，避免打断 HTML 阅读位置。

## 验收

内核验证 role/标记过滤、稳定排序与总数、线程跨文件夹分页、APPEND 大 payload 不进入摘要
通道。Rust 桥用真实 frontend 身份验证读写与活动投影；前端验证全身份、多选分组、部分失败、
旧响应、断连、搜索退出恢复、线程隔离与 unknown 确认。真 WKWebView 用虚构账户与临时库检查
浅色三栏、搜索、批量操作、会话与活动，不向真实邮箱发请求；深色与窄窗口增量视觉复核待补验。

实跑记录与视觉补验项见 [测试清单](../testing/README.md#m45-08-b统一工作区与同步活动adr-0037)。
