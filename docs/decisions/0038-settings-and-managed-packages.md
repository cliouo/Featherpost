# ADR-0038：08-C 账户、设置与受管扩展

- 状态：已接受，仓库实现完成；原生视觉补验未完成
- 日期：2026-09-23
- 前置：[前端授权](0030-frontend-authorization-closure.md)、[交付计划](../design/tauri/IMPLEMENTATION-PLAN.md)

## 界面与范围

沿用已认可的原窗口设置页、系统字体、灰白/深色和墨绿强调。账户、外观、阅读隐私、通知与规则、
地址、扩展和后台信息经 E01 设置贡献注册；不引入新的样式框架。账户按实际状态展示，编辑器
内聚探测与保存；扩展先列已安装项目，安装使用原生目录选择器和明确授权确认。
本片不自动切换默认前端，不移除 egui；外部 UI 隔离与扩展窗口仍归 E02/E03。

## 账户与秘密

复用 accounts_manage 下的版本化账户 API。IMAP/SMTP 使用明确服务器、端口、TLS 和认证字段，
探测分别展示收发结果；插件账户从已安装的 transport provider 选择，只读探测已有地址后绑定。
已有账户探测携带 id 与 expected_revision，网络等待前后校验版本，并把真实账户身份传给 provider；
新建探测仍省略身份，不会借用另一账户的绑定。
插件私有凭据继续由插件自己的管理入口处理，不在普通账户表单中猜测秘密格式或创建远程邮箱。
已有秘密不回填；用户本次输入仅存在编辑会话内，保存或放弃后清空，不进入浏览器存储、日志、
诊断或返回 DTO。版本冲突保留非秘密输入并要求刷新；不自动重复创建、移除或写入。

账户移除是软归档：显示准确账户及未完成队列提示，保留本地邮件，不删除服务器邮件。
有未保存编辑时离开设置、切分区与关窗均需明确放弃；正在提交时禁止重复操作。
读取失败、权限不足和重连不能表现成空列表或保存成功；旧连接、旧编辑器响应不能覆盖新状态。

## 规则、通知与地址

复用 get/setSettings、通知状态/显式授权、reading policy 与地址 API。保存以服务端回执为准，
区分仅当前运行时生效和已持久保存。通知首次读取不触发授权弹窗。
地址登记只管理本地发件身份，不宣称已创建服务器别名；SMTP 用户确认服务商已允许此地址。
当前插件发信只支持主地址时不提供可发别名创建，已有记录仍可读取、停用和移除。

## 包预览、事务与默认前端

增加 plugins_manage 管理方法：读取安装根、校验 staging/回滚预览、设置默认前端。
安装根仅供原生 Rust 复制器使用，不进入 JS。选择目录后先受限复制到该 daemon 的 staging，
再由 daemon 完整校验并返回名称、类型、版本、权限和生命周期；JS 仅持短命选择令牌。
提交使用同一 staging，清理取消/失败残留；源目录在预览后的变化不能改变待安装副本。
最多保留四份选择、十分钟过期，断线后的迟到令牌主动释放；单次只准备一份包。
不允许 JS 指定任意文件路径、RPC 方法或 staging 名。失败后不自动重试安装，先刷新实际清单。
回滚同样先展示目标版本和权限；停用/移除展示依赖账户。当前前端不可从自身界面移除。

默认前端选择持久在 frontend 安装根的隐藏状态文件，0600、单硬链接、拒绝符号链接，原子发布。
不存在时沿用 TOML 种子；损坏时保留原文件并拒绝修改，使用可用恢复入口。只允许选择在册前端，
禁止删除当前默认项；设置成功后才影响后续激活，不强行关闭当前窗口。管理事务串行化。
默认状态先于 TOML 种子做有效选择，删除旧种子后重启仍可恢复；隐藏管理条目不占包数量限额。
原子 rename 后若目录 fsync 失败，重读可见状态并冻结后续选择/移除，不能让内存保护另一个包。
移除已启用的服务包前先持久停用；若删除失败，包保持停用，刷新展示实际结果。independent 的
启用仅为持久意图，既不自动启动也不承诺停止用户自行启动的进程。扩展页刷新先调 refreshPlugins。
schema 保持 v10，现有 CLI/API 行为保持兼容。

## 验证

真实 frontend 身份验证账户版本冲突、权限拒绝、规则保存、地址生命周期、目录校验/安装/升级/
回滚/默认选择与重启；合成 IMAP/SMTP 探测不依赖真实账户。前端测试编辑丢弃、过期响应、
断线、不确定提交结果和 provider 能力。原生界面检查账户表单、扩展确认、明暗和窄窗口。

实际通过的自动化结果与工具不可用的视觉缺口见 [测试清单](../testing/README.md#m45-08-c账户设置与受管扩展adr-0038)。
