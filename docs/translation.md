# Featherpost Studio 邮件翻译使用与隐私指南

Featherpost Studio 内置安全、极简的邮件翻译能力，支持 **内置 OpenAI 兼容服务**（OpenAI、DeepSeek、自定义 HTTPS 中转、本机 Ollama 等）以及 **运行时热插拔的第三方翻译插件**。

---

## 1. 配置翻译服务（设置 › 翻译）

打开 **设置 › 翻译**（或通过命令面板 `⌘K` / `Ctrl+K` 搜索“翻译”）：

### 1.1 内置 OpenAI 兼容接口

1. 选择 **OpenAI 兼容接口（内置）**；
2. 可一键选用快捷预设或自定义接口地址：
   - **OpenAI**：`https://api.openai.com/v1`，推荐模型 `gpt-4o-mini`
   - **DeepSeek**：`https://api.deepseek.com/v1`，推荐模型 `deepseek-chat`
   - **本机 Ollama**：`http://127.0.0.1:11434/v1`（本机回环地址**无需填写 API 密钥**，且自动直连不绕经外部代理），填写已拉取的模型名（如 `qwen2.5:7b`）
   - **自定义中转 / 局域网服务**：
     - 公网地址**强制要求 `https://`**（拒绝公网明文 HTTP、重定向、内嵌 `user:pass@`、查询参数与片段）；
     - 局域网私有地址使用 `http://` 时，须显式勾选“我了解该局域网地址为明文 HTTP 传输”确认项后才允许测试或保存。
3. **凭据与服务地址绑定**：保存的 API 密钥与规范化后的服务地址（`scheme + host + port + API 根路径`）严格绑定。修改 Base URL 后，测试连接或保存留空均**不会**将旧服务的密钥发往新地址——必须输入新密钥或切换至免密钥本机回环服务。
4. 内置服务自动遵循 **设置 › 网络与代理** 的全局代理配置，并等待首个有效代理快照就绪后再发出请求（代理配置拉取失败时绝不静默切回直连）。
5. 点击 **测试连接** 验证可用性，确认后点击 **保存设置**。

> 配置存储在活动配置目录的 `translation_preference.toml` 中（Unix 权限 `0600` / Windows 用户私有 ACL），不会弹出 macOS Keychain 授权弹窗。

### 1.2 第三方热插拔翻译插件

如果你希望使用 DeepL、Google 或其他自定义翻译引擎：

1. 在 **设置 › 扩展** 安装声明了 `translation_provider` 能力的外部插件包（或使用 `featherpostctl plugin install --source <目录>`）；
2. 启用该插件；若插件自带设置界面（`ui_executable`），可在扩展页或翻译设置页点击 **打开插件设置** 进行配置；
3. 切回 **设置 › 翻译** 选择该插件并测试连接；
4. 若想自行开发第三方翻译插件，请参阅 [第三方热插拔翻译插件开发者指南](plugins/translation-provider.md)。

> **故障绝不静默切服务**：当你选中某个外部插件时，如果它被停用、离线或未注册，Featherpost 会在阅读区明确提示状态并提供前往设置的入口，绝不会把邮件悄悄改发给内置服务或其他插件。

## 2. 在阅读区使用邮件翻译

阅读区保持极简设计，不堆砌模式切换下拉菜单：

- **默认展示模式**与**目标语言**统一在 **设置 › 翻译** 配置：
  - **双语对照**：在原文段落与主题下方展示译文，便于核对术语与链接；
  - **仅译文**：以译文替换可翻译段落与主题，页面更清爽；
  - **零外发就地切换**：回到已翻译的邮件时，若你在设置页仅修改了展示模式（双语 ↔ 仅译文），阅读区会直接利用现有结果与本地缓存就地重绘，**不会**重新发送任何翻译请求。
- **一键工具栏按钮（`Shift+T`）**：
  - 未翻译时：单击立即按当前设置的展示模式与目标语言翻译；若尚未配置或插件离线，会明确提示并带你直达 **设置 › 翻译**；
  - 翻译中：再次单击立即取消在途请求；
  - 已翻译：按钮高亮激活，单击切回原文（保留本次翻译结果，再次点击可零请求瞬间恢复译文）。
- **单行外语检测横幅**：
  - 未配置翻译服务时**完全隐藏**检测横幅，零打扰（工具栏按钮仍常驻）；
  - 已配置服务且检出非目标语言邮件时，顶部显示单行提示：`检测到 {语言} 邮件` + **翻译** + **不再提示 {语言}** + `×`；
  - 翻译中显示分批进度 `正在翻译…（k / n）` + **取消**；
  - 翻译后显示 `已翻译（源语言 → 目标语言）` + **显示原文** + **重新翻译**（绕过本地缓存强制刷新）。
- **命令面板（`⌘K` / `Ctrl+K`）**：
  - 选中邮件后可直接执行 **翻译邮件**（`maild.mailbox.translate`）与 **重新翻译邮件**（`maild.mailbox.retranslate`）。

## 3. 本地译文缓存与空间回收

- **存储位置与内容**：译文按内容摘要保存在独立的本地 SQLite 数据库 `translation_cache.sqlite3` 中（与主邮件库隔离，**不包含**在常规主库在线备份之内），Unix 下 DB / WAL / SHM 均设为当前用户私有权限。
- **隐私提示**：**本地缓存文件包含本机可读的邮件译文文本**，默认配额为逻辑大小 **32 MiB**、最多 **2,000** 条、保留期限 **30 天**（过期自动清理）。
- **随时清空**：在 **设置 › 翻译 › 本地翻译缓存** 可分别查看逻辑配额与磁盘物理占用（DB / WAL / SHM），点击 **清空翻译缓存** 会立即逻辑删除全部缓存并递增 `clear_epoch` 防止在途翻译任务回写，随后在后台串行执行 `VACUUM` 与 `wal_checkpoint(TRUNCATE)` 回收磁盘空间。清空缓存不会影响原始邮件。

## 4. 外发隐私与安全边界

1. **按需外发**：默认不会自动发送邮件内容。只有当你手动点击翻译、点击检测横幅的“翻译”、触发快捷键/`⌘K`，或显式开启自动翻译时，可翻译正文段与主题才会发送给你选中的翻译服务。
2. **自动翻译显式绑定服务**：开启「自动翻译外语邮件」时，该授权严格绑定到当前选中的 Provider ID。**更换翻译服务后自动翻译会自动暂停**，需你重新确认后才会向新服务自动外发邮件；短邮件、验证码、语种不明确或已加入「永不自动翻译的语言」的邮件不会触发自动翻译。
3. **HTML 沙箱零 JS 隔离（ADR-0033）**：HTML 邮件的文本提取与译文重写全部在 Rust 侧完成，译文视图继续通过受控的 `featherpost-mail://` 协议加载在 `<iframe sandbox="">` 零脚本沙箱中，保留全部原有 CSP、外链确认与远程图片策略。原文链接地址以局部占位符保留在 Rust 侧，绝不发送给翻译模型；纯文本邮件通过纯文本 React 节点渲染，绝不注入任何 HTML。
4. **本地原生插件信任域**：外部翻译插件与守护进程运行在同一操作系统用户（同 UID）下，被选中的插件进程内存会接触待翻译的邮件正文。请仅安装来自可信作者的第三方插件。
