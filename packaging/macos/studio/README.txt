Featherpost Studio — macOS 13+ · Apple Silicon / Intel

先运行已安装的 Featherpost，然后双击「安装 Studio.command」。
安装器将 Studio 注册为独立前端并设为默认，再打开新版窗口。
升级会先通过 Studio 正常的草稿保存/退出流程关闭旧窗口；若退出被阻止则中止升级。
菜单栏、通知和新建邮件意图将交给 Studio。原版前端不会被删除。
已有账户、邮件、附件和草稿继续使用同一个本机后台，不迁移、不复制。

如需回退：双击「切回原版.command」，关闭 Studio，再从菜单栏打开邮箱。

这是 ad-hoc 签名的预览包，未经过 Apple 公证；macOS 若阻止打开，可在
系统设置 → 隐私与安全性中允许这次打开。

快捷键：⌘N 写邮件 · ⌘K 搜索 · ⌘, 设置 · ↑↓ 切换邮件 · Escape 返回列表
